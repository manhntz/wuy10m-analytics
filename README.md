# wuy10m-analytics

Static pages required by the TikTok for Developers app "Wuy10M Analytics" (internal, read-only analytics for our own TikTok accounts).

Published with GitHub Pages at https://manhntz.github.io/wuy10m-analytics/

- `index.html` – Web/Desktop URL
- `terms.html` – Terms of Service URL
- `privacy.html` – Privacy Policy URL
- `callback.html` – Login Kit redirect URI (shows the `code` returned by TikTok)
